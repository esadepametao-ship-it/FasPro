# FasPro – Facility Problem Reporting

> Report Problems, Improve Facilities.

## Deskripsi Singkat

FasPro (Facility Problem Reporting) merupakan aplikasi mobile berbasis Flutter yang dirancang untuk memudahkan mahasiswa, dosen, dan staf dalam melaporkan kerusakan fasilitas kampus.

Melalui aplikasi ini, pengguna dapat mengirimkan laporan kerusakan dengan menyertakan foto, deskripsi, serta lokasi fasilitas. Laporan yang masuk akan dikelola oleh admin dan diteruskan kepada teknisi untuk ditindaklanjuti.

FasPro bertujuan meningkatkan efektivitas pengelolaan fasilitas kampus serta mempermudah proses pelaporan, pemantauan, dan penanganan kerusakan.

## Rencana Fitur

1. **Login dan Register**
   Pengguna dapat membuat akun dan masuk ke aplikasi sesuai perannya.
2. **Pemilihan Lokasi Fasilitas**
   Pengguna dapat memilih gedung, ruangan, dan fasilitas kampus yang mengalami kerusakan.
3. **Pengaduan Kerusakan**
   Pengguna dapat mengirim laporan kerusakan dengan menyertakan foto, kategori fasilitas, lokasi, dan deskripsi masalah.
4. **Status Laporan**
   Pengguna dapat memantau perkembangan laporan melalui status Reported, Verified, Assigned, In Progress, dan Resolved.
5. **Manajemen Laporan Admin**
   Admin dapat melihat, memverifikasi, mengelola laporan, dan menugaskan teknisi.
6. **Penanganan oleh Teknisi**
   Teknisi dapat melihat tugas perbaikan, memperbarui status pengerjaan, serta mengunggah foto hasil perbaikan.
7. **Riwayat Pengaduan**
   Pengguna dapat melihat daftar laporan yang pernah dibuat beserta status penyelesaiannya.
8. **Notifikasi**
   Pengguna mendapatkan pemberitahuan mengenai perubahan status dan perkembangan laporan.
